How to use this

Finds the shortest sequence of anvil hits that gets you from a starting value to an exact target. Using a resource pack like "Perfected Anvil Helper" is very much recommended.

What to type

    Using a resource pack of your preference, check the exact final value for your desired result. Then type:

  • Just a target, like 78 - you'll then be asked for the sequence.
  • Just a sequence, like -15+7+2 - you'll then be asked for the target.
  • Both together on one line, like 78 -15+7+2 - solves immediately, no follow-up question.

Spaces are optional throughout - -15+7+2 and -15 +7 +2 are read the same way.

How input is told apart

Plain numbers with no sign, like 78 or 16, are always the target and starting point - they can never be mistaken for a sequence step. Anything signed (+7, -15) or the word hit is always part of the sequence.

The second number: starting point

When you type two plain numbers before the sequence, the first is the target and the second is where the gauge is already sitting - not 0. This is for when something went wrong mid-forge (a mistake or a missclick) and you need a fresh sequence from wherever the gauge actually landed, instead of from scratch.

For example, 78 16 +16 means: target 78, starting from 16 right now, then hit +16 once to finish.

Using hit

hit stands for an unspecified strike (-3, -6, or -9) - the solver tries all three and keeps whichever gives the shortest result. In Settings, you can set a shorthand symbol for it, e.g. *, so +7*+2 means +7 hit +2.

Reading the result

Four or more identical steps in a row are shown compacted, e.g. +16x4 instead of +16 +16 +16 +16.

Saving recipes

Name and save a result to keep it for next time. Search filters saved recipes by name as you type; clicking a saved recipe loads its sequence in a pop-up window.
